# MVP demo prompt — page inventory

Source: `originals/Arete-MVP-prompt.pdf`

**Purpose of this build:** clickable static demo + screenshots for cold email and a ~20-minute partner walkthrough (Capstone and other academy leadership). Not a live product.

## Specified stack

Static HTML/CSS/vanilla JS. Inter + Outfit + JetBrains Mono. Font Awesome. CSS variables for brand colors. Max content width 1200px. Breakpoints 768 / 1024.

## Pages in the prompt

**Student:** dashboard, practice, AI feedback, correction, matter test, drills, progress.

**Instructor:** dashboard, correction review, leaderboard.

**Optional:** marketing landing (`index.html`).

Login, org-code signup, and billing are **not** in the prompt.

## Resolved build decisions

1. Practice / feedback / correction / drills / instructor review use **THW ban advertising targeted at children**.
2. Matter tests are **current events / news** and do not need to match the practice motion.
3. Speaker label is **1st Proposition** (WSDC).
4. Logged-in student **Sarah Chen** is #1 (5/5); “You” rows must match that.
5. Org chrome: **Debate Academy**.
6. Include partner landing. Hand-off: clickable site + screenshot pack.
